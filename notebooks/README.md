# Notebooks

This folder contains the main learning and development notebooks for the project.

The notebooks are used to build each model step by step, connect theory directly to implementation, and record small experiments, visualizations, observations, and conclusions during development.

They are intentionally more explanatory and exploratory than the source files, so some code may be temporary or written mainly for learning and analysis.

The general progression is:

```text
Logistic Regression
        ↓
Softmax Regression
        ↓
PyTorch Softmax
        ↓
MLP
        ↓
CNN
        ↓
Vision Transformer
```

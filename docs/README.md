# Documentation

This folder contains the theoretical documentation for the project.

The notebooks focus on implementation and experimentation, while the documents here contain deeper explanations, mathematical derivations, and background concepts that would make the notebooks too dense.

The documentation is organized alongside the model progression so that each stage explains the theory introduced at that point.

Examples include:

- Mathematical foundations
- Gradient derivations
- Model limitations
- Architectural transitions
- Concepts reused by later models
